## What is dropped first if time runs short

W5 first (the GPU notebook is kept even if no reduced run completes), then the ROS 2 part of W7 (the Python loop is kept), then the replication part of W3. W10 is never skipped entirely.

## Parallel work

Helper agents search and digitise new curves (W3), retrieve the scaling law literature (W4) and gather retrieved sources for the field protocols (W8), each with a written brief, under the same full text rule as phase 3. A separate verifier checks every new curve and every new evidence row. The analysis and the writing are done by the lead.
